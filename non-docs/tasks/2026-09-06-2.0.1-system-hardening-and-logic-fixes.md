## 1. 📌 Objective & Scope (เป้าหมายและขอบเขตงาน)

ปรับปรุงแก้ไขจุดบกพร่อง (Bugs), ตรรกะที่ไม่รัดกุม (Edge Cases), และข้อขัดแย้งเชิงเอกสารที่ค้นพบจากการทำ **Comprehensive System, Logic & QA Audit (v2.0.0)** และผ่านการตรวจสอบอย่างเข้มข้นใน **Secondary Critical Audit & Zero-Blind-Spot Sanity Check** เพื่อยกระดับความแม่นยำ ประสิทธิภาพการประหยัดพลังงาน (Zero Background Overhead) และความสมบูรณ์แบบของแอปพลิเคชันสู่มาตรฐานสูงสุด ภายใต้กรอบ **Zero-Overhead Performance Budget (<35MB RAM, ~0.0% CPU ขณะ Idle)**

### 🎯 รายการจุดแก้ไขหลัก (Issues to Resolve):
1. 🚨 **Timer Drift on Minimized/Inactive Window (Wall-Clock Delta Engine with Drift-Free Remainder Preservation)**: 
   - แก้ไขการนับถอยหลังใน `usePomodoroTimer.ts` และ `pomodoroStore.ts` ให้คำนวณตามเวลาจริง (Wall-clock Delta) โดยวัดจากผลต่างเวลา (`Date.now() - lastTickRef.current`) แทนการนับลด `-1` ตายตัว
   - เพิ่มตัวดักจับ `visibilitychange` และ `window.focus` เพื่อ Re-sync ทันทีเมื่อกลับสู่หน้าจอ
   - **Hardening Rules**: 
     - *Drift-Free Remainder Preservation*: เมื่อ `elapsed >= 1` ให้อัปเดต `lastTickRef.current += elapsed * 1000` (ห้ามใช้ `lastTickRef.current = now` เพื่อป้องกันการปัดเศษมิลลิวินาทีทิ้งสะสมเป็นนาทีในระยะยาว)
     - *Cap at Current Phase End*: หาก Sleep นานจน `deltaSeconds >= remainingSeconds` ให้ตัดจบเฟสปัจจุบันเพียง 1 ครั้ง ไม่ทำ Multi-phase Cascading
     - *Anti-Double-Tick Guard*: ซิงค์ `lastTickRef.current` ร่วมกันระหว่าง Interval และ Visibility Event
     - *Negative Delta Guard*: ป้องกันกรณีเวลาเครื่องถูกเลื่อนย้อนหลังด้วย `Math.max(0, ...)` และหาก `now < lastTickRef.current` ให้รีเซ็ต `lastTickRef.current = now` ทันที
     - *Resume/Start Re-sync*: รีเซ็ต `lastTickRef.current = Date.now()` เสมอเมื่อ `status` เปลี่ยนเป็น `RUNNING`
2. ⚠️ **Web Audio Lifecycle Hardening (Debounced Auto-Suspend & Node GC)**: 
   - เพิ่มการตัดการเชื่อมต่อโหนด (`osc.disconnect()`, `gain.disconnect()`) พร้อมบล็อก `try-catch` ใน `osc.onended` ใน `soundSynth.ts` เพื่อคืน Memory ให้ V8 Garbage Collector
   - เพิ่มระบบ Debounced Auto-Suspend หน่วงเวลา 3.0 วินาทีหลังจบคอร์ดระฆัง พร้อม `clearTimeout` ก่อนหน้า เพื่อป้องกันการตัดเสียงรอบใหม่กะทันหัน และคืนทรัพยากรเสียงให้ Windows `audiodg.exe` สู่โหมดประหยัดพลังงาน
3. ⚠️ **Prevent Focus Streak Inflation on Manual Skip**: 
   - ปรับพารามิเตอร์ `skipPhase(completedNaturally: boolean = false)` ใน `pomodoroStore.ts`
   - คิดคะแนน Focus Streak และสะสมนาทีโฟกัสเฉพาะเมื่อ `completedNaturally === true` (ผ่าน `tick()`) เท่านั้น การกดปุ่ม `⏭ Skip` จากผู้ใช้จะไม่เพิ่ม Streak
4. ⚠️ **Context Menu Right-Edge Clipping Fix**: 
   - ปรับตัวแปร `MENU_WIDTH` ใน `PetContextMenu.tsx` จาก `210` เป็น `240` ให้ตรงกับ CSS `max-width: 240px` ป้องกันเมนูถูกขอบหน้าต่างเดสก์ท็อปขนาด 320px ตัดแหว่งเมื่อคลิกขวาฝั่งขวา
5. 💡 **Dynamic Companion Icon in WindowHeader**: 
   - เปลี่ยนการฮาร์ดโค้ด `🐰` ใน `WindowHeader.tsx` ให้แสดงอีโมจิประจำตัวของ Companion ที่กำลังเลือกใช้งานอยู่จริงตาม `activeCompanionId` จาก `companionStore`
6. 💡 **Long Break Cycle 4 UI Display & Reset Logic**: 
   - ให้ `currentCycle` คงค่าเป็น `4` ในระหว่างช่วงพักผ่อน `LONG_BREAK` เพื่อให้ผู้ใช้ทราบว่าเพิ่งพิชิต Milestone รอบที่ 4 สำเร็จ (แสดงผล 4/4 Dots เต็มใน Modal)
   - รีเซ็ต `currentCycle = 1` ทันทีเมื่อสิ้นสุด `LONG_BREAK` และเริ่ม `FOCUS` ลูปใหม่
7. 💡 **Technical Documentation Sync**: 
   - แก้ไขข้อความใน `non-docs/specs/version-roadmap.md` ให้ระบุฟีเจอร์ Opacity แทน Window Scale และแก้ไขคอมเมนต์ JSDoc ใน `types/companion.ts` ให้ระบุขนาด Prop เป็น 28x20 px ตรงกับความเป็นจริง

## 2. 🗺️ Architecture & Flow Diagrams

### A. Wall-Clock Delta Precision Timer Flow (ป้องกัน Timer Drift & Fractional Truncation)

```mermaid
flowchart TD
    Start["▶ Start / Resume Timer"] --> RecordNow["บันทึก lastTickRef = Date.now()"]
    RecordNow --> Listener["ทำงานคู่ขนาน:\n1. setInterval (1,000ms)\n2. visibilitychange / focus Event"]
    
    Listener --> MeasureDelta["คำนวณ Delta:\nnow = Date.now()\ndeltaMs = now - lastTickRef\nelapsed = max(0, floor(deltaMs / 1000))"]
    
    MeasureDelta --> NegativeCheck{"now < lastTickRef ?\n(เวลาเครื่องถูกปรับย้อนหลัง)"}
    NegativeCheck -->|Yes| ResetClockGuard["lastTickRef = now\nelapsed = 0"]
    NegativeCheck -->|No| CheckElapsed{"elapsed >= 1 ?"}
    ResetClockGuard --> WaitNext["รอ Tick รอบถัดไป"]
    
    CheckElapsed -->|No| WaitNext["รอ Tick รอบถัดไป\n(รักษาเศษเสี้ยววินาทีไว้ใน lastTickRef)"]
    CheckElapsed -->|Yes| UpdateRef["lastTickRef += elapsed * 1000\n(รักษาเศษมิลลิวินาทีไว้รอบถัดไป ไร้ Drift สะสม)"]
    
    UpdateRef --> ApplyTick["pomodoroStore.tick(elapsed)"]
    ApplyTick --> CheckRemain{"remaining > elapsed ?"}
    
    CheckRemain -->|Yes| NormalDec["remaining -= elapsed\nอัปเดต UI ทันที"]
    CheckRemain -->|No (หมดเฟส / Sleep นาน)| CapPhaseEnd["🚨 Cap at Phase End:\nจบเฟสปัจจุบัน 1 ครั้ง\nskipPhase(completedNaturally = true)"]
    
    CapPhaseEnd --> Transition["สลับไปยังเฟสถัดไป\nและเล่นเสียงระฆังเตือน 🔔"]
```

### B. Web Audio Zero-Overhead Lifecycle Flow (Debounced Suspend & Node Disconnect)

```mermaid
flowchart TD
    Trigger["🔔 playChimeSound() Triggered"] --> ClearTimer{"มี suspendTimeoutId เดิมค้างอยู่หรือไม่?"}
    ClearTimer -->|มี| CancelTimeout["clearTimeout(suspendTimeoutId)"]
    ClearTimer -->|ไม่มี| CheckCtx
    CancelTimeout --> CheckCtx{"AudioContext มีอยู่หรือไม่?"}
    
    CheckCtx -->|ยังไม่มี| CreateCtx["new AudioContext()"]
    CheckCtx -->|มีอยู่แล้ว (Suspended)| ResumeCtx["await audioCtx.resume()"]
    
    CreateCtx --> PlayNotes["สร้าง Osc + Gain Nodes\nกำหนด Exponential Decay"]
    ResumeCtx --> PlayNotes
    
    PlayNotes --> OnEnded["Event: osc.onended"]
    OnEnded --> DisconnectNodes["try { osc.disconnect(); gain.disconnect(); }\n(ปล่อยให้ V8 GC กวาด Memory ทันที 🧹)"]
    
    PlayNotes --> DebounceSuspend["ตั้ง Timeout 3.0s (Debounced)\nsuspendTimeoutId = setTimeout(...)"]
    DebounceSuspend --> SuspendCtx["audioCtx.suspend()\n(Windows audiodg.exe คืน CPU 0.0% 💤)"]
```

## 4. ⚖️ Trade-off & Decision Analysis

| ประเด็นการตัดสินใจ | ข้อดี (Pros) | ข้อเสีย / สิ่งที่ต้องระวัง (Cons) | ข้อสรุปเชิงสถาปัตยกรรม (Resolution) |
| :--- | :--- | :--- | :--- |
| **A. Cap at Phase End vs Multi-Phase Simulation** | ไม่เกิด False Streak และเสียงระฆังไม่ตีรัวเมื่อเปิดเครื่องหลัง Sleep นาน | เวลาที่เครื่องหลับไปจะไม่ถูกนำมาจำลองเฟสถัดๆ ไป | **Cap at Phase End**: เหมาะสมกับ Pomodoro ในชีวิตจริงที่สุด เพราะเมื่อผู้ใช้ไม่อยู่ ระบบไม่ควรแอบรันเซสชันต่อเอง |
| **B. Drift-Free Remainder Preservation (`+= elapsed * 1000`)** | กำจัดปัญหา Fractional Truncation Drift สะสม 100% เที่ยงตรงระดับ Atomic Clock ตลอดการทำงาน 8+ ชั่วโมง | ต้องระวังกรณีเวลาเครื่องถูกปรับย้อนหลัง (Negative Delta) | **ใช้ `+= elapsed * 1000` ร่วมกับ Negative Delta Guard**: รักษาเศษมิลลิวินาทีไว้อย่างเที่ยงตรง ปลอดภัยสูงสุด |
| **C. Debounced Audio Suspend (3.0s)** | ประหยัดพลังงานระดับฮาร์ดแวร์ Windows (`audiodg.exe` คืน CPU 0.0%) ไร้ปัญหา Audio Popping | มีการถือ Timeout ID 1 ตัวในหน่วยความจำ | **Debounced Suspend**: เพิ่ม `clearTimeout` ป้องกันการขัดจังหวะเสียงใหม่ คุ้มค่าและประหยัดพลังงานสูงสุด |
| **D. Manual Skip ไม่คิด Streak** | สถิติ Daily Streak สะท้อนความตั้งใจและวินัยจริงของผู้ใช้ ป้องกัน Cheat | ผู้ใช้ที่ทำงานเสร็จก่อน 1 นาทีแล้วกดข้าม จะไม่ได้แต้ม | แนะนำให้ผู้ใช้ปล่อยให้เวลานับจบปกติ เพื่อความเที่ยงตรงของบันทึกสถิติ |
| **E. คง Cycle 4 ระหว่าง LONG_BREAK** | UI ใน Modal แสดงจุดไข่ปลา 4/4 dots เต็ม สื่อถึงความสำเร็จอย่างภาคภูมิใจ | ต้องดูแลเงื่อนไขรีเซ็ตเป็น 1 เมื่อเริ่ม Focus ลูปใหม่ | **Transition Matrix ที่ชัดเจน**: กำหนดให้ `LONG_BREAK -> FOCUS` รีเซ็ต `currentCycle = 1` เสมอ |
