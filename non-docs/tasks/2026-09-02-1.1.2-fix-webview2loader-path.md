## 📌 1. ปัญหาและสาเหตุ (Problem & Root Cause)

```mermaid
flowchart TD
    subgraph Buggy_Flow_v1.1.1 ["❌ v1.1.1 Packaging Issue"]
        A1["Tauri bundle.resources: ['resources/WebView2Loader.dll']"] --> B1["NSIS installs to $INSTDIR/resources/WebView2Loader.dll"]
        C1["User runs $INSTDIR/Lo-fi Bun Companion.exe"] --> D1["Windows Dynamic Linker searches $INSTDIR/ and System32"]
        D1 -.->|Cannot find DLL in subfolder| E1["💥 Launch Crash / Missing DLL Error"]
    end

    subgraph Fixed_Flow_v1.1.2 ["✅ v1.1.2 Dual-Layer Defense"]
        A2["Tauri Mapping: resources/WebView2Loader.dll -> WebView2Loader.dll"] --> B2["NSIS installs directly to $INSTDIR/WebView2Loader.dll"]
        C2["main.rs startup calls SetDllDirectoryW(resources/)"] --> D2["Dynamic Linker checks both $INSTDIR/ and $INSTDIR/resources/"]
        D2 --> E2["🎉 100% Reliable Native Startup on all Windows Machines"]
    end
```

### รายละเอียดข้อผิดพลาด:
1. ในเวอร์ชัน 1.1.1 มีการกำหนด `resources: ["resources/WebView2Loader.dll"]` ซึ่ง Tauri Bundler นำไปวางไว้ใน `$INSTDIR/resources/WebView2Loader.dll`
2. ระบบปฏิบัติการ Windows มีลำดับการค้นหา DLL (Dynamic Link Library Search Order) โดยจะตรวจสอบที่ Directory ของ `.exe` และ System Paths แต่ไม่ค้นหาในโฟลเดอร์ย่อย `resources/`
3. ทำให้เครื่องที่ไม่ได้ติดตั้ง WebView2 Runtime แบบ System-wide หรือเครื่อง Standalone พบปัญหาไม่สามารถเริ่มทำงานได้
