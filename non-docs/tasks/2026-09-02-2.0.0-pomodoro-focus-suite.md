## 1. 📌 Objective & Scope (เป้าหมายและขอบเขต)
ยกระดับ `lofi-bun-companion` จาก Desktop Mascot สู่ **Productivity Desk Companion** เต็มรูปแบบ ด้วยระบบ **Pomodoro Focus Suite** พร้อมระบบ **Rest Automation (กล่อมน้องสัตว์เลี้ยงหลับเมื่อหมดเวลาทำงาน)** และการปรับปรุง **Context Menu Overhaul** ให้รองรับการเลื่อนดูเมนูด้วย Lo-fi Slim Scrollbar ป้องกันปัญหาเมนูล้นขอบหน้าต่างเดสก์ท็อปอย่างสมบูรณ์แบบ

### ฟีเจอร์หลักใน Release 2.0.0:
1. 🍅 **Pomodoro State Engine & Flexible Intervals**:
   - Classic 25/5 min (Focus 25 min, Short Break 5 min)
   - Deep Work 50/10 min (Focus 50 min, Short Break 10 min)
   - Custom Timer Mode (ผู้ใช้ตั้งเวลา Focus และ Break ได้เองตามใจชอบ)
   - Long Break Automation: เมื่อทำ Focus ครบ 4 รอบ จะเข้าสู่รอบพักผ่อนยาว (Long Break 15-20 min) อัตโนมัติ
   - LocalStorage Persistence: บันทึกข้อมูล Daily Focus Streak (🍅 x N รอบ) และเวลารวมที่โฟกัสในแต่ละวัน
2. 💤 **Rest Automation Hook (Companion Sleep Sync)**:
   - เมื่อหมดเวลา Focus และเข้าสู่ช่วงพักผ่อน (`SHORT_BREAK` หรือ `LONG_BREAK`) น้องสัตว์เลี้ยงจะเปลี่ยนท่าทางเป็น `REST` (นอนกอดหมอน / แช่น้ำส้มยูซุ / จิบชาอุ่น) อัตโนมัติ เพื่อเตือนให้ผู้ใช้พักสายตา
   - เมื่อเข้าสู่โหมด `FOCUS` จะกลับสู่สถานะมอนิเตอร์ฮาร์ดแวร์ตามปกติ
3. 🔔 **Zero-Asset Web Audio Soft Chime & Desktop Notifications**:
   - สร้างเสียงเตือน Soft Bell Chime นุ่มนวลผ่าน Web Audio API (Zero external MP3 overhead)
   - ระบบ Lazy Audio Context initialization ที่ปลอดภัย ไม่บล็อกเบราว์เซอร์หรือเดสก์ท็อป
   - Desktop Notification แจ้งเตือนเมื่อจบรอบ Focus หรือ Break
4. 🪟 **Floating Mini Progress Widget & Full Focus Dashboard Modal**:
   - Mini Circular Progress Ring หรือ Mini Pill บน Mascot สำหรับดูเวลาอย่างรวดเร็ว (มี Toggle เปิด/ปิด)
   - Full Focus Dashboard Modal สไตล์ Cozy Glassmorphism เปิดได้จาก Double-click บน Mascot หรือคลิกขวา Context Menu
5. 📜 **Context Menu Overhaul & Lo-fi Slim Scrollbar (Overflow Fix)**:
   - เพิ่มปุ่ม Quick Pomodoro Controls ใน Context Menu (Start 25m Focus, Pause, Open Dashboard)
   - ปรับ Submenu "Switch Companion" ให้ยุบ (Collapse) เป็นค่าเริ่มต้นเพื่อความกะทัดรัด
   - ใส่ `max-height` พร้อม Custom Lo-fi Slim Scrollbar ป้องกันไม่ให้เมนูล้นขอบหน้าต่างขนาด 380px ของ Tauri
6. 🧪 **5-Pillar Automated Quality Gates (`npm run verify`)**:
   - ผ่านเกณฑ์ 100%: Linting, Formatting, Strict Typecheck, Vitest Unit Tests (พร้อม Time-mocking), และ Production Build

## 2. 🗺️ Architecture & State Machine Flow

```mermaid
flowchart TD
    subgraph PomodoroEngine["1. Pomodoro State Machine (pomodoroStore)"]
        Idle["IDLE\n(Standby)"] -->|Start Focus| Focus["FOCUS Phase\n(25m / 50m / Custom)"]
        Focus -->|Pause / Resume| Focus
        Focus -->|Tick 00:00 (Cycles 1-3)| ShortBreak["SHORT_BREAK Phase\n(5m / 10m)"]
        Focus -->|Tick 00:00 (Cycle 4 Complete)| LongBreak["LONG_BREAK Phase\n(15m - 20m)"]
        ShortBreak -->|Next Focus| Focus
        LongBreak -->|Reset / New Day| Idle
    end

    subgraph CompanionSync["2. Companion Rest Automation Hook"]
        Focus -.->|Active Focus| MascotActive["Hardware Telemetry Pose\n(IDLE / FOCUS / FRENZY / DISK / RAM)"]
        ShortBreak -.->|Break Phase| MascotRest["Auto Override: REST Pose 💤\n(Lavender Pillow / Hot Spring / Cozy Nap)"]
        LongBreak -.->|Deep Break| MascotRest
    end

    subgraph AudioAndFeedback["3. Cozy Feedback Layer"]
        Focus -->|Finish Focus| ChimeSound["🔔 Soft Bell Chime (Web Audio API)"]
        Focus -->|Finish Focus| Toast["🍵 Cozy Toast: พักสายตา ดื่มน้ำอุ่นๆ กันนะ"]
    end
```
