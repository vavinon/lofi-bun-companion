## 🚀 Execution & Verification: Release 2.0.1 (System Hardening & QA Fixes)
- **Status**: 🟢 Complete & Verified (180/180 Vitest Suites Passing)
- **Delivered Changes**:
  1. **Zustand Store Hardening (`pomodoroStore.ts`)**:
     - เพิ่มพารามิเตอร์ `tick(deltaSeconds?: number)` (default = 1) พร้อมตัดจบเฟสทันทีหาก `remaining <= delta` ป้องกัน sleep overshoot
     - เพิ่มพารามิเตอร์ `skipPhase(completedNaturally?: boolean)` (default = false) บันทึกคะแนน Daily Streak (🍅) และสะสมนาทีโฟกัสเฉพาะเมื่อจบธรรมชาติเท่านั้น
     - คงค่า `currentCycle = 4` ใน `LONG_BREAK` เพื่อให้ Modal แสดงผล 4/4 dots ครบถ้วน และรีเซ็ตเป็น 1 เมื่อเริ่ม Focus ลูปใหม่
  2. **Wall-Clock Delta Precision Timer (`usePomodoroTimer.ts`)**:
     - คำนวณ delta จาก `Date.now() - lastTickRef.current`
     - นำเทคนิค Drift-Free Remainder Preservation (`lastTickRef.current += elapsed * 1000`) มาใช้เพื่อกำจัดข้อผิดพลาดการปัดเศษมิลลิวินาทีสะสม
     - ดักจับ `visibilitychange` และ `window.focus` เพื่อ Re-sync ตัวจับเวลาทันทีหลังหลับ/สลับแท็บ
     - ติดตั้ง Negative Delta Guard ป้องกันกรณีเวลาเครื่องถูกปรับย้อนหลัง
  3. **Web Audio Lifecycle Hardening (`soundSynth.ts`)**:
     - ผูก `osc.onended` สั่ง `osc.disconnect()` และ `gain.disconnect()` คืน Memory ให้ V8 Garbage Collector ทันที
     - นำระบบ Debounced Auto-Suspend หน่วง 3.0 วินาที พร้อม `clearTimeout` ดักรอบใหม่ คืนทรัพยากรเสียงให้ Windows `audiodg.exe` สู่โหมด 0.0% CPU
  4. **Context Menu Width Alignment (`PetContextMenu.tsx`)**:
     - ปรับ `MENU_WIDTH = 240` ตรงกับ CSS `max-width: 240px` ป้องกันขอบขวาแหว่ง
  5. **Dynamic Companion Icon (`WindowHeader.tsx`)**:
     - แสดงอีโมจิประจำตัวของ Companion ที่เลือกใช้งานจริงจาก `activeCompanionId` แทนการฮาร์ดโค้ด
