## 💡 Decisions Made (ADR)
- **Language Policy**: Thai for conversational interactions & brainstorming; English for codebase, comments, types, and git commits.
- **Workflow Pattern**: Plan-First protocol — every feature must start with a dated task proposal before code execution.
- **Code Simplicity & Modularity (KISS)**: Strictly avoid over-engineering. Keep files focused and granular (<100-150 lines), clearly separating types, stores, components, and utils. Every function and state machine logic must include meaningful English comments explaining the "Why".
- **5-Pillar Quality Gate Protocol**: Every task completion and commit requires `npm run verify` to pass 100% (1: ESLint, 2: Prettier, 3: TypeScript Typecheck, 4: Vitest Unit Tests, 5: Vite Build).
- **5-Gen Master Roadmap Strategy**: 
  - **Gen 1 (v0.1 - v1.0)**: Dedicated 100% to the Flagship **🐰 Lo-fi Bun** (Core Engine, Widget Physics, Tactile Petting, Pomodoro, and Hardware Polling) with zero overhead.
  - **Gen 1 Expansion (v1.5)**: **Browser Companion Extension** (Side Panel, New Tab, Tab-count reactivity via `chrome.system` & `chrome.tabs`).
  - **Gen 2 (v2.0+)**: Major expansion **"Bun & Friends + Modding"** introducing the other 5 animals (*Neko, Shiba, Capybara, Cockatiel, Dolphin*) and Custom Modded Skins.
- **Distribution & Packaging**: Tauri v2 for ultra-lightweight Desktop binaries (Windows Single-File Portable `.exe` / `.msi`, macOS `.dmg`, Linux `.AppImage`) + WebExtension Manifest V3 for all modern browsers.
- **Cozy Emotional Value ("สัตว์เลี้ยงแก้เหงา")**: Added tactile interactions (head pats, heart floaters, AFK sleepy state) so the pets feel alive and emotionally comforting rather than just passive hardware gauges.

- **Zero-Overhead & Layering Strategy**: Decoupled Base Animal Body (CSS Step animations) from Dynamic Prop Overlays (RAM burden props). Implemented state priority evaluation to prevent CPU overhead and jitter.
- **Hardware Integration**: Animals animate based on real-time CPU/RAM/Disk metrics with 1.5s polling to guarantee near-zero CPU footprint (<0.05ms reading time).
- **Privacy & Security**: Standard user-level API calls only; zero telemetry and completely offline.
- **Testing Strategy**: Vitest + React Testing Library for fast, automated unit/integration tests on Timer, State Machine, and Stores.
- **Timer Flexibility**: Pomodoro and timer suites are fully toggleable so users can choose between pure desk pet mode and focused productivity mode.
- **Audio Strategy (Optional)**: Audio & Soundscape mixer shifted to an optional/toggleable feature (muted by default) to keep the app ultra-lightweight, zero idle audio memory, and respect users who already play music via Spotify/YouTube.
