### 2. Disk I/O Real-Time Activity Fix (`telemetry.rs`)
- **ปัญหา**: `HardwareSampler` ดึงข้อมูลจาก `Disks` เพื่อหา used space / total space ซึ่งเป็นตัวชี้วัดความจุคงที่ (Static Capacity)
- **การแก้ไข**:
  - เปลี่ยนมาใช้ `sysinfo::ProcessRefreshKind::new().with_disk_usage()` เพื่อดึง delta read/write bytes ของทุก process บนระบบปฏิบัติการ
  - คำนวณอัตรา Data Transfer Rate (Throughput ในหน่วย MB/s)
  - กำหนด Ceiling Saturation ไว้ที่ 50 MB/s สำหรับแมปเป็นค่า 0.0–100.0% Disk Activity
  - เพิ่ม Rust Unit Tests (`telemetry::tests`) ตรวจสอบความถูกต้องและขอบเขตค่า

### 3. WebView2Loader.dll Native Bundling
- **ปัญหา**: เครื่องผู้ใช้บางรายที่ไม่มี WebView2 Runtime ติดตั้งในระบบ อาจเปิดแอปพลิเคชันไม่ขึ้นเนื่องจากขาด DLL
- **การแก้ไข**:
  - คัดลอก `WebView2Loader.dll` ไปยัง `src-tauri/resources/WebView2Loader.dll`
  - ตั้งค่า `"resources": ["resources/WebView2Loader.dll"]` ใน `tauri.conf.json` เพื่อให้ NSIS Installer แนบ DLL ไปยัง Target Directory โดยอัตโนมัติ
